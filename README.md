# Игра «Тысяча»

## Описание проекта

Проект представляет собой реализацию карточной игры «Тысяча» на языке Java.

Программа состоит из библиотеки классов, реализующих игровую механику, и консольного приложения для запуска и симуляции партии.

## Используемые технологии

- Java 24
- Maven
- JUnit 5
- Git

## Правила игры

В игре участвуют три игрока. Используется колода из 24 карт: от девятки до туза в каждой из четырёх мастей.

Основные этапы раунда:

1. Раздача по семь карт каждому игроку и формирование прикупа из трёх карт.
2. Торговля игроков за право забрать прикуп (минимальный заказ — 100 очков, шаг — 5).
3. Передача прикупа победителю торговли и снос трёх карт.
4. Розыгрыш семи взяток с обязательным ответом в масть.
5. Объявление марьяжей (король и дама одной масти, начиная со второй взятки), которые приносят дополнительные очки и назначают козырную масть.
6. Подсчёт очков и проверка выполнения заказа.

Цель игры — первым набрать не менее 1000 очков.

В игре предусмотрены:
- **Очковый барьер 880**: игрок, не делавший заказ в раунде, не может подняться выше 880 очков за счёт взяток.
- **Штрафные «болты»**: за три подряд невыполненных заказа начисляется болт; при накоплении трёх болтов с игрока списывается 120 очков.

## Архитектура и структура проекта

Механика игры полностью отделена от консольного вывода: движок изменяет состояние партии и фиксирует происходящее в журнале событий.

- `model` — доменные объекты (`Card`, `Deck`, `Player`, `Bid`, `TrumpSuit`, `GameSettings`) и перечисления с полями (`Suit`, `Rank`).
- `engine` — игровая логика (`GameEngine`, `Dealer`, `Auction`, `TalonExchange`, `Trick`, `MarriageManager`, `RoundScorer`).
- `state` — реализация паттерна **State** для пошагового управления фазами раунда (`GameState`, `GamePhase` и состояния от инициализации до завершения).
- `events` — журнал игровых событий (`GameLog`).
- `rules` — константы правил игры (`GameRules`).
- `util` — компараторы для сортировки карт (`CardComparators`).
- `console` — консольное приложение (`Main`).

## Запуск проекта

Для запуска необходимы JDK 24 и Apache Maven.

Сборка проекта и запуск через Maven:

```bash
mvn compile exec:java -Dexec.mainClass="ru.vsu.thousand.console.Main"
```

Также проект можно открыть в IntelliJ IDEA и запустить метод `main` в классе `ru.vsu.thousand.console.Main`.

## Воспроизводимость

Все случайные операции (перемешивание колоды) используют единый экземпляр `java.util.Random`, инициализируемый параметром `seed` в `GameSettings`. При одинаковом значении `seed` ход партии полностью воспроизводится.

## Тестирование

Для запуска модульных и интеграционных тестов выполните:

```bash
mvn test
```

Тесты реализованы на JUnit 5 и проверяют правила на граничных ситуациях (барьер 880, три болта, марьяжи, снос, взятки), обработку недопустимых действий и воспроизводимость полной партии.
